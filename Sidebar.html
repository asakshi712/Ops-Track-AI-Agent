OpsTrack Quick Guide

1. Employee

Open Employee_Console. Enter a Ticket ID for portal tasks or a short evidence link/message for the daily update in column H.

2. Complete once

Tick Mark Complete in column I. The system logs who/when/proof and advances the next due date automatically.

3. Manager

Review overdue tasks. Tick Manager Acknowledged in column L and add the follow-up note in column M.

4. Admin

Set manager and leadership recipients in Config. Use OpsTrack > Run SLA check now for a controlled test.

Prototype note: Google Sheets permissions and Apps Script email authorization are required. Start with dummy data and test email addresses.
